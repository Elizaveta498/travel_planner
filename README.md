✈️ Планировщик путешествий



Веб-приложение для планирования путешествий с настройками в cookies.



🚀 Установка



1\. Активируйте venv: `venv\\Scripts\\activate`

2\. Установите зависимости: `pip install -r requirements.txt`

3\. Запустите сервер: `python manage.py runserver`

4\. Откройте в браузере: http://127.0.0.1:8000/

&#x20;📋 Функционал



\- Просмотр популярных направлений

\- Настройка темы (светлая/темная/синяя)

\- Выбор валюты (USD/EUR/RUB)

\- Сохранение настроек в cookies
